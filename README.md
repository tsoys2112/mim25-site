# Сайт MIM25: каталог, прайс-лист и заявки

Каталог из 469 товаров с розничными ценами (прайс-лист от 30.09.2026). Клиент собирает заявку, она сохраняется в базу Turso. Менеджер видит заявки на странице `/admin.html`.

## Из чего состоит проект

| Файл / папка | Что это |
|---|---|
| `index.html` | Сам сайт: каталог, поиск, корзина-заявка |
| `admin.html` | Страница заявок для менеджера (вход по паролю) |
| `data/products.json` | Товары и цены для сайта |
| `img/` | Фото брендов из каталога |
| `api/order.js` | Приём заявки и запись в базу |
| `api/orders.js` | Выдача заявок менеджеру, смена статуса |
| `api/_db.js` | Подключение к Turso |
| `api/_products.js` | Цены для проверки заявок на сервере |

## Переменные окружения (задаются в Vercel)

| Имя | Откуда взять |
|---|---|
| `TURSO_DATABASE_URL` | Turso → ваша база → URL (начинается с `libsql://`) |
| `TURSO_AUTH_TOKEN` | Turso → ваша база → Create Token |
| `ADMIN_PASSWORD` | Придумайте сами: пароль для входа на `/admin.html` |

Таблица `orders` в базе создаётся автоматически при первой заявке.

## Как обновить сайт

Измените файлы в репозитории на GitHub. Vercel сам заметит изменения и через минуту опубликует новую версию.

Чтобы обновить цены, нужно заново сгенерировать `data/products.json` и `api/_products.js` из нового прайса.
